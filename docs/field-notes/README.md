## 所以它到底记住了什么

上面两张图里，它记得的东西分三种，而插件现在只做得好第一种：

| 它记得的 | 例子 | 现状 |
|---|---|---|
| **事实** | root 没给、Steam 排序停在「游戏时间」 | ✅ L3 就是干这个的 |
| **翻车** | 9 点开会那条迟到 21 小时才弹 | ⚠️ 被压成摘要，**推理没了** |
| **流程** | 那个 docx 为什么那样排、那次点击为什么没反应 | ⚠️ **整个丢了**，只剩「做过」 |
| **聊了一半的话题** | —— | ⚠️ 没有这个概念 |

**「记得住翻车」比「记得住事实」难**：事实是个名词，翻车是一段因果——发生了什么、当时怎么判断的、后来错在哪。压缩成一句「那次提醒延迟了」之后，下次还会再犯。

**「聊了一半的话题」更麻烦**：它现在按会话切块，一个话题横跨三次对话就断了。而人不是这么记事的。

这一节存在的意义，是区分「它看起来记得」和「它真的记得」。
