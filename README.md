# dsh-memory

**给你的 AI 装上不会忘的记忆。**

每次开新会话，AI 都从零开始 —— 昨天定的方案、上周踩的坑、你的偏好，全都不记得了。

dsh-memory 给 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（dsh）补上这一块：**跨会话记住该记的，忘掉该忘的，还不会记串。**

---

## 它做什么

**记住事实，不记流水账.**
你说过的「默认模型用 deepseek-flash」「服务器在东京」——它归成一条条事实存下来，下次开口它就记得。事实变了就**追加新版本，旧版本永远留着**（所以它能回答"这个是什么时候改的、为什么改"）。

**每次开口，先递一份简报.**
新会话一开始，它把当前状态摘要交给模型 —— 模型不用重新摸索你之前干到哪了。

**夜里自己整理.**
到点自动扫一遍最近聊的，把反复出现的线索整理进长期记忆、更新简报。**只加，不删。**

---

## 为什么不是又一个「记忆 RAG」

大多数「AI 记忆」是个黑盒向量库 —— 存进去的东西，你看不见、动不了。

dsh-memory 反过来：**记忆就是几个明文的文件**，躺在你自己的磁盘上。

- 你**能打开看**（Markdown + YAML，不是二进制黑盒）
- 你**能手动改**（记错了不用求 AI 忘掉，自己改）
- 你**能搬走**（换成别的工具也读得懂）
- 而且「只追加不删」是**写死在代码里**的 —— 它不可能偷偷把你的事实抹掉

---

## 装上

```bash
dsh plugin --profile <你的profile> add <这个包 / 包名 / GitHub 地址>
```

装上即挂载，并自动注册夜间整理 —— 不用额外配置。

想调（可选）：整理时间、时区、用哪个模型、记忆存放目录，都在 profile 的 `cordis.patch.yml` 里覆盖。

---

## 它给了 AI 六只手

| 工具 | 做什么 |
|---|---|
| `memory_brief` | 读当前简报 |
| `memory_recall` | 按关键词 / 标签翻记忆 |
| `memory_note` | 记一条事实（同主题自动出新版本） |
| `memory_candidate` | 记一条「待确认」的线索 |
| `memory_promote` | 把线索升格成正式事实 |
| `memory_organize` | 手动整理一次（支持试跑） |
